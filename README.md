# HOUSE OF SAVAGE

**Luxury Jewelry. Timeless Elegance. Modern Experience.**

House of Savage is a luxury jewelry storefront focused on diamond jewelry, moissanite pieces, and gold jewelry, presented through a refined black-and-white visual identity.

This project is a frontend modernization of the original website, rebuilt with a modern React ecosystem and an emphasis on performance, responsive design, and elegant interactions.

## ✨ Features

- **Luxury Editorial Design** — Minimalist black-and-white styling with refined typography and premium imagery.
- **Animated Hero Carousel** — Automatically scrolling jewelry imagery with hover-pause behavior.
- **Responsive Navigation** — Adaptive navigation and mobile-friendly layouts.
- **Product Collections** — Dedicated browsing experiences for jewelry categories and watches.
- **Product Galleries** — Scrollable media galleries with deferred video loading.
- **Scroll Animations** — Subtle reveal effects and smooth transitions throughout the experience.
- **Newsletter Interface** — Subscription UI ready for integration with an email marketing service.
- **Account Pages** — Login and registration interfaces ready for authentication integration.
- **Optimized Media** — WebP image assets and performance-conscious media loading.
- **Reusable Components** — Shared layouts and components for a more maintainable codebase.

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript / TSX
- Tailwind CSS
- CSS animations and transitions
- Next.js Image optimization

## 🚀 Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm.

### Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate into the project directory:

```bash
cd House-of-Savage-Refactor
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

To check the production build:

```bash
npm run build
```

Start the production server after a successful build:

```bash
npm run start
```

## 🎨 Design Philosophy

The visual direction centers on:

- Monochrome styling and understated luxury.
- Product imagery as the primary visual focus.
- Smooth, restrained motion rather than distracting effects.
- Consistent experiences across mobile, tablet, and desktop.
- Clean, maintainable code that supports future improvements.

## 🔌 Integrations and Deployment

The newsletter and authentication interfaces require their respective service or backend integrations before they can process real subscriptions or authenticate users.

Before production deployment, verify product information, image-to-product matching, environment variables, and all interactive features.

The application can be deployed to a compatible Next.js hosting platform, such as Vercel, after a successful production build.
